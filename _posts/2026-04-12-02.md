# 자바 메서드
자바에서 **메서드(Method)**는 특정 작업을 수행하기 위해 명령문들을 하나로 묶어놓은 **코드의 집합**입니다.<br>
다른 언어에서는 '함수(Function)'라고도 부르지만, 객체지향인 자바에서는 클래스 안에 존재하므로 보통 메서드라고 부릅니다.

### 1\. 메서드의 기본 구조
메서드는 크게 **선언부(Header)**와 **구현부(Body)**로 나뉩니다.<br>
$$\text{[제어자] [반환타입] [메서드명] ( [매개변수] ) \{ [수행할 코드] \}}$$

| **구성 요소** | **설명** |
|---|---|
| **제어자 (Modifier)** | public, private, static 등 접근 권한이나 성격을 지정합니다. |
| **반환 타입 (Return Type)** | 결과값의 데이터 타입입니다. 결과가 없으면 void를 씁니다. |
| **메서드명 (Name)** | 메서드를 호출할 때 사용하는 이름입니다. |
| **매개변수 (Parameters)** | 입력값으로 받을 데이터들입니다. (생략 가능) |
| **구현부 (Body)** | { } 안에 실제 실행할 코드를 작성합니다. |

### 2\. 메서드의 종류와 호출 방식
자바 메서드는 크게 두 가지로 구분됩니다. 메모리에 올라가는 방식과 호출하는 방법이 다릅니다.<br><br>
**① 클래스 메서드 (Static Method)**
* **특징:** static 키워드가 붙어 있으며, 객체를 생성하지 않아도 바로 사용할 수 있습니다.
* **호출:** 클래스이름.메서드이름()
* **예시:** Math.abs(), Integer.parseInt()

⠀**② 인스턴스 메서드 (Instance Method)**
* **특징:** 객체(Instance)에 소속된 메서드입니다. 반드시 new 연산자로 객체를 생성해야 호출할 수 있습니다.
* **호출:** 참조변수.메서드이름()

⠀
### 3\. 메서드 오버로딩 (Overloading)
한 클래스 내에 **이름이 같은 메서드를 여러 개 정의**하는 것을 말합니다. 단, 매개변수의 **개수**나 **타입**이 달라야 합니다.

``` Java

public class MyMath {
    // 1번: 정수 두 개 더하기
    int add(int a, int b) { return a + b; }

    // 2번: 실수 두 개 더하기 (오버로딩)
    double add(double a, double b) { return a + b; }
    
    // 3번: 매개변수 개수가 다름 (오버로딩)
    int add(int a, int b, int c) { return a + b + c; }
}

```

### 4\. 메서드를 왜 쓸까요?
**1** **재사용성:** 한 번 정의해두면 언제든 다시 불러올 수 있습니다.<br>
**2** **중복 제거:** 반복되는 코드를 하나로 묶어 효율적으로 관리합니다.<br>
**3** **가독성:** 전체적인 코드의 흐름을 파악하기 쉬워집니다.
