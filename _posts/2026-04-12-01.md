자바에서 **증감 연산자(++, --)**는 변수의 값을 1씩 증가시키거나 감소시킬 때 사용합니다. 위치에 따라 연산 순서가 완전히 달라지기 때문에 정확히 구분하는 것이 중요합니다.

### 1\. 전위 증감 연산자 (Prefix)
연산자가 변수 **앞**에 붙는 형태입니다 (예: ++a, --a).
* **원칙:** "먼저 계산하고, 나중에 대입한다."
* **동작:** 현재 실행 중인 라인에서 값을 먼저 1 증가/감소시킨 후, 그 결과값을 해당 식에 사용합니다.

``` java
int a = 5;
int b = ++a; 

// 결과: a = 6, b = 6
// 과정: a를 먼저 6으로 만든 뒤, 그 값을 b에 넣음
```



### 2\. 후위 증감 연산자 (Postfix)
연산자가 변수 **뒤**에 붙는 형태입니다 (예: a++, a--).
* **원칙:** "먼저 대입하고, 나중에 계산한다."
* **동작:** 현재 변수의 기존 값을 식에 먼저 사용한 뒤, 해당 라인의 실행이 끝나면(세미콜론을 만나면) 값을 1 증가/감소시킵니다.

``` java
int a = 5;
int b = a++; 

// 결과: a = 6, b = 5
// 과정: 기존의 a(5)를 b에 먼저 넣고, 그 다음 a를 6으로 만듦
```

### 3\. 한눈에 비교하기

| 구분 | 형태 | 의미 | 연산 순서 |
|:---:|:---:|:---:|:---:|
| **전위** | `++i` | 1 증가 후 사용 | **1순위:** 값 증가 $\rightarrow$ **2순위:** 나머지 연산 |
| **후위** | `i++` | 사용 후 1 증가 | **1순위:** 나머지 연산 $\rightarrow$ **2순위:** 값 증가 |

### 4\. 주의해야 할 예시
반복문이나 복합 수식에서 사용할 때 헷갈리기 쉽습니다.

``` java
int x = 10;
int y = 20;

int result = (++x) + (y--); 
// 1. ++x 실행: x는 11이 됨
// 2. x(11) + y(20) 수행: result는 31
// 3. y-- 실행: y는 19가 됨

System.out.println(result); // 31
System.out.println(x);      // 11
System.out.println(y);      // 19

```
